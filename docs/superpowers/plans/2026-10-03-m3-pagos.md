# M3 Pagos y seguridad: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo:** reemplazar el botón «simular pago» por una pasarela simulada independiente (`mock-gateway`). La pasarela genera un QR dinámico por el monto exacto, tiene una página de «celular que paga» y entrega una confirmación firmada con JWT RS256. El quiosco la valida antes de mostrar W4. La comunicación entre ambos va por HTTPS con TLS 1.3.

**Arquitectura:** `mock-gateway/` es un servicio FastAPI aparte (puerto 8443, HTTPS) que guarda los cobros en memoria y firma la confirmación con su clave privada. `kiosk-api` gana `payments.py`, con el cliente HTTP (TLS 1.3 obligatorio), el verificador JWT y la protección contra reenvíos. `KioskService` crea el cobro en `pay()` y consulta la pasarela (**polling**, 1 vez por segundo) en estado PAYING. `kiosk-ui` dibuja el QR. Las claves y certificados de desarrollo los genera `python -m gateway.devkeys` en `keys/`, que está fuera de git.

**Stack:** Python 3.12, FastAPI, PyJWT[crypto], cryptography, httpx · npm `qrcode`.

**Spec:** [`docs/superpowers/specs/2026-10-03-autocheckout-design.md`](../specs/2026-10-03-autocheckout-design.md) · Base: planes M0 y M2

## Restricciones globales

- JWT: algoritmo **solo RS256**. Claims obligatorios: `iss`, `aud`, `iat`, `exp`, `jti`, más `charge_id`, `amount_cents` y `status`. `exp` = `iat` + **300 s**.
- `iss = "autocaja-mock-gateway"`, `aud = "autocaja-kiosk"`.
- Un `jti` ya usado se rechaza (anti-reenvío).
- W4 aparece **solo** si el token es válido, `status == "PAID"`, el `charge_id` es el del cobro en curso y `amount_cents` es igual al total del carrito (3.4.4.3).
- Cliente del quiosco hacia la pasarela: `ssl.TLSVersion.TLSv1_3` como versión **mínima** y certificado verificado contra `keys/ca.pem` (RNF-04).
- La pasarela exige la cabecera `X-API-Key`, comparada con `hmac.compare_digest`. La clave sale de la variable de entorno `GATEWAY_API_KEY`; nunca va al repositorio.
- Las claves y certificados van en `keys/` (ya ignorado por `.gitignore`).
- Se elimina `/sim/pay` y `KioskService.simulate_payment`: el pago solo entra por la pasarela.
- Polling cada **1,0 s** en PAYING, con timeout HTTP de **2 s**. Si la pasarela falla, se queda en QR y se registra en el log (no se cae). El cobro se cancela a los 120 s (eso ya existe).
- Se mantienen las restricciones de M0 y M2. Ramas cortas por tarea, unidas con `merge --no-ff` a `feature/m3-pagos`. Sin Co-Authored-By.

```python
"""Genera claves y certificados SOLO para desarrollo en <repo>/keys/ (fuera de git)."""

import datetime as dt
import ipaddress
from pathlib import Path

from cryptography import x509
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import ec, rsa
from cryptography.x509.oid import ExtendedKeyUsageOID, NameOID

REPO = Path(__file__).resolve().parents[3]

NO_PASSWORD = serialization.NoEncryption()


def _write_private(path: Path, key) -> None:
    path.write_bytes(
        key.private_bytes(
            serialization.Encoding.PEM, serialization.PrivateFormat.PKCS8, NO_PASSWORD
        )
    )


def write_signing_keys(out: Path) -> None:
    key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
    _write_private(out / "gateway_jwt_private.pem", key)
    (out / "gateway_jwt_public.pem").write_bytes(
        key.public_key().public_bytes(
            serialization.Encoding.PEM, serialization.PublicFormat.SubjectPublicKeyInfo
        )
    )


def write_tls_certs(out: Path) -> None:
    now = dt.datetime.now(dt.UTC)
    start = now - dt.timedelta(minutes=5)

    ca_key = ec.generate_private_key(ec.SECP256R1())
    ca_name = x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, "AutoCaja Dev CA")])
    ca_cert = (
        x509.CertificateBuilder()
        .subject_name(ca_name)
        .issuer_name(ca_name)
        .public_key(ca_key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(start)
        .not_valid_after(now + dt.timedelta(days=365))
        .add_extension(x509.BasicConstraints(ca=True, path_length=0), critical=True)
        .add_extension(
            x509.KeyUsage(
                digital_signature=True,
                content_commitment=False,
                key_encipherment=False,
                data_encipherment=False,
                key_agreement=False,
                key_cert_sign=True,
                crl_sign=True,
                encipher_only=False,
                decipher_only=False,
            ),
            critical=True,
        )
        .add_extension(
            x509.SubjectKeyIdentifier.from_public_key(ca_key.public_key()), critical=False
        )
        .sign(ca_key, hashes.SHA256())
    )

    server_key = ec.generate_private_key(ec.SECP256R1())
    server_cert = (
        x509.CertificateBuilder()
        .subject_name(x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, "localhost")]))
        .issuer_name(ca_name)
        .public_key(server_key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(start)
        .not_valid_after(now + dt.timedelta(days=90))
        .add_extension(
            x509.SubjectAlternativeName(
                [x509.DNSName("localhost"), x509.IPAddress(ipaddress.ip_address("127.0.0.1"))]
            ),
            critical=False,
        )
        .add_extension(x509.BasicConstraints(ca=False, path_length=None), critical=True)
        .add_extension(x509.ExtendedKeyUsage([ExtendedKeyUsageOID.SERVER_AUTH]), critical=False)
        .add_extension(
            x509.SubjectKeyIdentifier.from_public_key(server_key.public_key()), critical=False
        )
        .add_extension(
            x509.AuthorityKeyIdentifier.from_issuer_public_key(ca_key.public_key()),
            critical=False,
        )
        .sign(ca_key, hashes.SHA256())
    )

    (out / "ca.pem").write_bytes(ca_cert.public_bytes(serialization.Encoding.PEM))
    (out / "server.pem").write_bytes(server_cert.public_bytes(serialization.Encoding.PEM))
    _write_private(out / "server-key.pem", server_key)


def main() -> None:
    out = REPO / "keys"
    out.mkdir(exist_ok=True)
    write_signing_keys(out)
    write_tls_certs(out)
    print(f"Claves y certificados de desarrollo creados en {out}")


if __name__ == "__main__":
    main()
```

```python
import secrets
import time
import uuid
from dataclasses import dataclass

import jwt

ISSUER = "autocaja-mock-gateway"
AUDIENCE = "autocaja-kiosk"
TOKEN_TTL_S = 300


@dataclass
class Charge:
    id: str
    amount_cents: int
    reference: str
    status: str = "PENDING"


class ChargeStore:
    def __init__(self) -> None:
        self._charges: dict[str, Charge] = {}

    def create(self, amount_cents: int, reference: str) -> Charge:
        charge = Charge(secrets.token_urlsafe(12), amount_cents, reference)
        self._charges[charge.id] = charge
        return charge

    def get(self, charge_id: str) -> Charge | None:
        return self._charges.get(charge_id)

    def mark_paid(self, charge_id: str) -> Charge:
        charge = self._charges[charge_id]
        charge.status = "PAID"
        return charge


def sign_payment(charge: Charge, private_key_pem: bytes, now: float | None = None) -> str:
    issued = int(time.time() if now is None else now)
    claims = {
        "iss": ISSUER,
        "aud": AUDIENCE,
        "iat": issued,
        "exp": issued + TOKEN_TTL_S,
        "jti": str(uuid.uuid4()),
        "charge_id": charge.id,
        "amount_cents": charge.amount_cents,
        "status": charge.status,
    }
    return jwt.encode(claims, private_key_pem, algorithm="RS256")
```

```python
import hmac
from html import escape

from fastapi import FastAPI, Header, HTTPException
from fastapi.responses import HTMLResponse
from pydantic import BaseModel, Field

from gateway.charges import Charge, ChargeStore, sign_payment

PAGE = """<!doctype html>
<html lang="es"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Pago simulado</title>
<style>
body {{ font-family: system-ui, sans-serif; max-width: 420px; margin: 2rem auto; padding: 0 1rem;
       text-align: center; }}
.amount {{ font-size: 2.5rem; font-weight: 700; margin: 1rem 0; }}
button {{ font-size: 1.2rem; padding: 1rem; width: 100%; border: 0; border-radius: 12px;
          background: #0f6e5c; color: #fff; }}
</style></head><body>
<p>Celular simulado · billetera de prueba</p>
<div class="amount">{amount}</div>
{body}
</body></html>"""


class ChargeIn(BaseModel):
    amount_cents: int = Field(gt=0, le=1_000_000)
    reference: str = Field(min_length=1, max_length=64)


def _soles(cents: int) -> str:
    return f"S/ {cents / 100:.2f}"


def create_app(private_key_pem: bytes, api_key: str, public_url: str) -> FastAPI:
    store = ChargeStore()
    app = FastAPI(title="mock-gateway")

    def require_key(given: str | None) -> None:
        if given is None or not hmac.compare_digest(given, api_key):
            raise HTTPException(status_code=401, detail="API key inválida")

    def find(charge_id: str) -> Charge:
        charge = store.get(charge_id)
        if charge is None:
            raise HTTPException(status_code=404, detail="Cobro no encontrado")
        return charge

    @app.post("/charges", status_code=201)
    def create_charge(body: ChargeIn, x_api_key: str | None = Header(default=None)) -> dict:
        require_key(x_api_key)
        charge = store.create(body.amount_cents, body.reference)
        return {
            "charge_id": charge.id,
            "qr_payload": f"{public_url}/pay/{charge.id}",
            "status": charge.status,
        }

    @app.get("/charges/{charge_id}")
    def get_charge(charge_id: str, x_api_key: str | None = Header(default=None)) -> dict:
        require_key(x_api_key)
        charge = find(charge_id)
        out = {"charge_id": charge.id, "status": charge.status}
        if charge.status == "PAID":
            out["token"] = sign_payment(charge, private_key_pem)
        return out

    @app.get("/pay/{charge_id}", response_class=HTMLResponse)
    def pay_page(charge_id: str) -> str:
        charge = find(charge_id)
        if charge.status == "PAID":
            body = "<p>Este cobro ya fue pagado.</p>"
        else:
            body = (
                f'<form method="post" action="/pay/{escape(charge.id)}/confirm">'
                "<button>Pagar con Yape/Plin (simulado)</button></form>"
            )
        return PAGE.format(amount=_soles(charge.amount_cents), body=body)

    @app.post("/pay/{charge_id}/confirm", response_class=HTMLResponse)
    def confirm(charge_id: str) -> str:
        charge = store.mark_paid(find(charge_id).id)
        return PAGE.format(amount=_soles(charge.amount_cents), body="<p>✅ Pago realizado</p>")

    return app
```

```python
import os

from gateway.app import create_app

    keys = REPO / "keys"
```

```python
import time
import uuid

import jwt
from cryptography.hazmat.primitives import serialization
from cryptography.hazmat.primitives.asymmetric import rsa

from kiosk.payments import AUDIENCE, ISSUER, Charge, PaymentError

_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
PRIVATE_PEM = _key.private_bytes(
    serialization.Encoding.PEM, serialization.PrivateFormat.PKCS8, serialization.NoEncryption()
)
PUBLIC_PEM = _key.public_key().public_bytes(
    serialization.Encoding.PEM, serialization.PublicFormat.SubjectPublicKeyInfo
)


def sign(private_pem: bytes = PRIVATE_PEM, **overrides) -> str:
    now = int(time.time())
    claims = {
        "iss": ISSUER,
        "aud": AUDIENCE,
        "iat": now,
        "exp": now + 300,
        "jti": str(uuid.uuid4()),
        "charge_id": "ch_1",
        "amount_cents": 250,
        "status": "PAID",
    }
    claims.update(overrides)
    return jwt.encode(claims, private_pem, algorithm="RS256")


class FakeGateway:
    """Pasarela falsa para las pruebas: cobra, y entrega un token firmado cuando `paid`."""

    def __init__(self) -> None:
        self.paid = False
        self.fail_create = False
        self.fail_poll = False
        self.paid_amount: int | None = None
        self.amounts: list[int] = []
        self.polls = 0

    def create_charge(self, amount_cents: int, reference: str) -> Charge:
        if self.fail_create:
            raise PaymentError("pasarela caída")
        self.amounts.append(amount_cents)
        return Charge("ch_1", "https://localhost:8443/pay/ch_1")

    def poll(self, charge_id: str) -> str | None:
        self.polls += 1
        if self.fail_poll:
            raise PaymentError("pasarela caída")
        if not self.paid:
            return None
        amount = self.paid_amount if self.paid_amount is not None else self.amounts[-1]
        return sign(charge_id=charge_id, amount_cents=amount)
```

```python
import ssl
from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

import httpx
import jwt

ISSUER = "autocaja-mock-gateway"
AUDIENCE = "autocaja-kiosk"
HTTP_TIMEOUT_S = 2.0


class PaymentError(Exception):
    pass


@dataclass(frozen=True)
class Charge:
    id: str
    qr_payload: str


@dataclass(frozen=True)
class PaymentEvent:
    charge_id: str
    amount_cents: int


class PaymentGateway(Protocol):
    def create_charge(self, amount_cents: int, reference: str) -> Charge: ...

    def poll(self, charge_id: str) -> str | None: ...


class JwtVerifier:
    """Valida la confirmación firmada RS256 de la pasarela y rechaza reenvíos (jti)."""

    def __init__(self, public_key_pem: bytes):
        self._key = public_key_pem
        self._seen: set[str] = set()

    def verify(self, token: str) -> PaymentEvent:
        try:
            claims = jwt.decode(
                token,
                self._key,
                algorithms=["RS256"],
                audience=AUDIENCE,
                issuer=ISSUER,
                options={"require": ["exp", "iat", "iss", "aud", "jti"]},
            )
        except jwt.PyJWTError as e:
            raise PaymentError(f"Token de pago inválido: {e}") from e
        if claims.get("status") != "PAID":
            raise PaymentError("El pago no figura como realizado")
        if claims["jti"] in self._seen:
            raise PaymentError("Token de pago reutilizado")
        self._seen.add(claims["jti"])
        return PaymentEvent(str(claims["charge_id"]), int(claims["amount_cents"]))


def tls13_context(ca_file: Path | str) -> ssl.SSLContext:
    ctx = ssl.create_default_context(cafile=str(ca_file))
    ctx.minimum_version = ssl.TLSVersion.TLSv1_3
    return ctx


class HttpGateway:
    def __init__(
        self,
        base_url: str,
        api_key: str,
        ca_file: Path | None = None,
        transport: httpx.BaseTransport | None = None,
    ):
        self._client = httpx.Client(
            base_url=base_url,
            headers={"X-API-Key": api_key},
            timeout=HTTP_TIMEOUT_S,
            verify=tls13_context(ca_file) if ca_file else True,
            transport=transport,
        )

    def _call(self, method: str, path: str, **kwargs) -> dict:
        try:
            response = self._client.request(method, path, **kwargs)
            response.raise_for_status()
            return response.json()
        except (httpx.HTTPError, ValueError) as e:
            raise PaymentError(f"Error con la pasarela: {e}") from e

    def create_charge(self, amount_cents: int, reference: str) -> Charge:
        data = self._call("POST", "/charges", json={"amount_cents": amount_cents, "reference": reference})
        return Charge(data["charge_id"], data["qr_payload"])

    def poll(self, charge_id: str) -> str | None:
        return self._call("GET", f"/charges/{charge_id}").get("token")
```

````markdown
## Probar el sistema (simulado)

Requisitos: Python 3.12 y Node 22 o superior. En cada terminal Python define la misma clave:
`export GATEWAY_API_KEY=una-clave-larga-cualquiera` (ver `.env.example`).

```bash
# Terminal 1: pasarela de pago simulada (HTTPS :8443)
cd mock-gateway
python -m venv .venv && source .venv/Scripts/activate   # Linux/Mac: .venv/bin/activate
pip install -e ".[dev]"
python -m gateway.devkeys        # solo la primera vez: crea keys/ (fuera de git)
python -m gateway

# Terminal 2: API del quiosco (:8000)
cd kiosk-api
python -m venv .venv && source .venv/Scripts/activate
pip install -e ".[dev]"
python -m kiosk

# Terminal 3: interfaz (:5173)
cd kiosk-ui
npm install
npm run dev
```

| URL | Para qué |
|---|---|
| http://localhost:5173/ | Quiosco (cliente), formato vertical |
| http://localhost:5173/sim | Simulador: poner productos, esconder peso y abrir el «celular» que paga |
| http://localhost:5173/caja | Panel de caja: solicitudes de ayuda y reactivar el quiosco |

Para pagar: en la pantalla del QR, abre en `/sim` el enlace «Abrir el celular simulado» y pulsa «Pagar con Yape/Plin (simulado)». El quiosco consulta la pasarela por HTTPS (TLS 1.3), verifica la firma RS256 y muestra el ticket.

La API escucha en 127.0.0.1:8000 y solo acepta peticiones desde http://localhost:5173 (Vite usa ese puerto fijo; si está ocupado, libéralo).
````
